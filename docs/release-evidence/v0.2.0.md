Notes:

- This release carries the profiles-audit fix cycle (batches A-F):
  storage hardening with an advisory-lock write path, the private-key
  passphrase tri-state (profiles.json v2 -> v3 in-place migration),
  deletion reference decoupling, cross-instance write serialization for
  recents/config/residual stores, and connection-keyed remote-edit
  identity. Details and deliberately-declined work:
  `docs/plans/2026-08-22-profiles-audit-fix-cycle.md`.
- The passphrase policy toggle is the only new interactive surface;
  native smoke must specifically cover all three states plus migration
  of a pre-0.2.0 profiles.json.
- The public GitHub release contains source archives only. The generated
  app bundle remains unsigned and is not attached as a distributable
  binary.
