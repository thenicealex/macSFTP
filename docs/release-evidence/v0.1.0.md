Notes:

- Interactive items above were manually tested by the user on a native macOS
  build and signed off on 2026-08-01. Remaining unchecked gates are scripted or
  CI-only, not interactive: `scripts/test_password_auth.sh` (requires a running
  Docker daemon) and the primary `iconutil` bundle path confirmation.
- Application signing and notarization are intentionally outside the 0.1.0
  source-readiness gate. Do not publish the unsigned bundle as a public release.
- macOS local-network privacy handling is implemented and build-gated. Because
  this build is intentionally unsigned, the operating system may not preserve
  its privacy identity across rebuilds; stable permission identity remains part
  of the future Developer ID signing gate.
- Native GUI inspection confirmed two simultaneous windows in the Window menu,
  About version 0.1.0, Settings rendering, and the unsigned arm64 bundle launch.
  Window restore/close-order and the remaining interactive items were
  subsequently signed off by user manual testing on 2026-08-01.
- The sandboxed bundle build used the deterministic ICNS fallback after
  `iconutil` reported `Invalid Iconset`. The resulting ICNS is recognized by
  macOS tooling, but native CI must confirm the primary `iconutil` path before
  release evidence can pass.
